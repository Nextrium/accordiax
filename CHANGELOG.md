## 0.1.0 – 2026-10-23

First release from this repository.

### Added
- Deal workflow: requests, offers, price negotiation, agreements, payment hold, delivery, disputes and appeals, chat, ratings, identity checks and payout requests.
- Contributor guide, handbook, security policy, code of conduct and licence file.
- CI checks: build, end-to-end smoke tests, secret scan and migration guard.
- Lint baseline so new code can't add violations.

### Changed
- Deploys run from CI only, through protected environments.
