# Security policy

## Reporting a vulnerability

Please report security problems privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability**.

Don't open a public issue, pull request or discussion about a vulnerability.

Include what you found, how to reproduce it, and what an attacker could do with it. Please don't access other people's data, move real money, or run tests that could disrupt the service.

## What to expect

- We confirm receipt within **3 working days**.
- We tell you our assessment and planned fix within **10 working days**.
- We credit you in the release notes when the fix ships, unless you'd rather we didn't.

## Supported versions

Only the latest release on `main` (the production site) is supported.
